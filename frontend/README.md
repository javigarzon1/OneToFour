# OneToFour Frontend

Frontend de OneToFour construido con Vue 3, Vue Router y Vite.

## Ejecutar

npm install
npm run dev

Si VITE_API_URL está vacío, la aplicación funciona en modo demo con datos locales.

Cuando exista el backend, configurar VITE_API_URL y utilizar:
- GET /api/questions
- POST /api/games
- GET /api/ranking
